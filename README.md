# 📚 Biblioteca Impossível

### Nem todo livro é aquilo que parece.

Uma experiência interativa onde **literatura encontra Inteligência Artificial**.

Em cada rodada, três livros são apresentados.
Dois são reais. **Um foi criado por IA.**

Você consegue descobrir qual?

---

## 🎮 Como funciona

**01** → Analise os três livros
**02** → Observe capa, autor, ano e sinopse
**03** → Escolha aquele que parece ter sido criado por IA
**04** → Descubra a resposta
**05** → Acumule pontos
